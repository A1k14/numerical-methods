# Лабораторна робота №1: Уточнення дійсних коренів нелінійних рівнянь

Командний проєкт для 4 учасників з чисельних методів.
Задана точність: $\varepsilon = 0.001$.

---

## 👥 Розподіл завдань у команді

| Файл | Метод | Хто відповідає |
| :--- | :--- | :--- |
| `bisection.py` | **Метод дихотомії** (половинного ділення) | 👤 Учасник 1 |
| `chord.py` | **Метод хорд** (Regula Falsi) | 👤 Учасник 2 |
| `newton.py` | **Метод Ньютона** (дотичних) | 👤 Учасник 3 |
| `simple_iteration.py` | **Метод простої ітерації** | 👤 Учасник 4 |

---

## 📁 Структура проєкту

```text
lab1/
├── equations.py            # Формули рівнянь з методички f(x), похідні f'(x), phi(x), [a, b]
├── bisection.py            # Код методу дихотомії
├── chord.py                # Код методу хорд
├── newton.py               # Код методу Ньютона
├── simple_iteration.py     # Код методу простої ітерації
├── main.py                 # Головний запуск: розрахунок усіх методів, таблиця і графік
├── requirements.txt        # Бібліотеки для графіка (matplotlib)
└── .gitignore              # Ігнорування службових файлів
```

---

## 🚀 Як користуватися проєктом

### 1. Встановлення залежностей (для графіків)
У терміналі:
```bash
pip install -r requirements.txt
```

### 2. Як змінити рівняння під свій варіант
Відкрийте файл `equations.py`:
- У блоці **1. АЛГЕБРАЇЧНЕ РІВНЯННЯ** замініть функцію `f_alg`, похідні `df_alg`, `d2f_alg`, форму `phi_alg` та межі `a_alg, b_alg, x0_alg`.
- У блоці **2. ТРАНСЦЕНДЕНТНЕ РІВНЯННЯ** зробіть те саме для вашого трансцендентного рівняння.

> **Важливо:** Більше ніде у проєкті формули змінювати не потрібно! Усі 4 методи автоматично підтягнуть ваші нові рівняння.

### 3. Тестування власного методу окремо
Кожен розробник може запустити свій власний файл напряму (наприклад, правою кнопкою миші `Run 'newton.py'`).
У кінці кожного файлу є вбудований міні-тест, який перевіряє роботу методу автономно.

### 4. Запуск повної програми для звіту
Запустіть файл `main.py`:
```bash
python main.py
```
Програма:
1. Запустить усі 4 методи для алгебраїчного рівняння.
2. Запустить усі 4 методи для трансцендентного рівняння.
3. Надрукує красиві порівняльні таблиці з коренями, кількістю ітерацій, нев'язкою та часом розрахунку.
4. Побудує та збереже графіки швидкості збіжності у файл `convergence_plot.png`.
