# Лабораторна робота №1: Уточнення дійсних коренів нелінійних рівнянь

Командний проєкт з чисельних методів для 4 учасників.  
Задана точність: $\varepsilon = 0.001$.

---

## 👥 Розподіл завдань у команді

| Файл | Метод | Відповідальний |
| :--- | :--- | :--- |
| `bisection.py` | **Метод дихотомії** (половинного ділення) | 👤 **Тарас** |
| `chord.py` | **Метод хорд** (Regula Falsi) | 👤 **Степан** |
| `newton.py` | **Метод Ньютона** (дотичних) | 👤 **Саша** |
| `simple_iteration.py` | **Метод простої ітерації** | 👤 **Данік** |

---

## 📁 Структура проєкту

```text
lab1/
├── equations.py            # Формули f(x), похідні f'(x), phi(x) для 2 рівнянь
├── bisection.py            # Метод дихотомії (Тарас)
├── chord.py                # Метод хорд (Степан)
├── newton.py               # Метод Ньютона (Саша)
├── simple_iteration.py     # Метод простої ітерації (Данік)
├── main.py                 # Запуск усіх 4 методів, порівняння та побудова графіків
├── requirements.txt        # Залежності (matplotlib)
└── .gitignore              # Ігнорування службових файлів (.venv, .idea тощо)
```

---

## 🚀 Як користуватися

1. **Встановити залежності:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Змінити рівняння під свій варіант:**
   У файлі `equations.py` задати функції $f(x)$, похідні $f'(x), f''(x)$ та відрізки $[a, b]$ для алгебраїчного і трансцендентного рівнянь.

3. **Запустити підсумковий звіт:**
   ```bash
   python main.py
   ```
